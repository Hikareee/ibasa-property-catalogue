# IBASA Property Catalogue

Premium flip-book catalogue for IBASA (PT. Integrasi Bangun Perkasa). Each listing has a 3D massing in the background and a dedicated **3D Preview** button.

## Local

```bash
npm install
npm run dev
```

Open [http://localhost:5173](http://localhost:5173).

## Deploy

This is a Vite app. Vercel detects the framework from `vercel.json`. Production build is `npm run build` → `dist`.
